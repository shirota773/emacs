# AGENTS.md

This file defines the operational rules for the Antigravity AI assistant in this repository.

## Git Workflow

- **Branch Management**: Always create a new branch from `main` when editing or adding files under Git control. Never work directly on `main`.
- **Session Progress**: Commit changes frequently during a session to manage work progress.
- **Merging**: When merging work back into `main`, use squash merges to keep the history clean. Intermediate session commits should be consolidated.

## Priority
- Antigravity MUST follow the rules in this file.
- If technical details about the repository are needed, refer to `CLAUDE.md` if available, but prioritize this file for operational behavior.
